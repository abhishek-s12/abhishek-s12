## Building

**[trustgate](https://github.com/abhishek-s12/trustgate)** — Verification-first tooling for AI coding agents. Agents now ship code faster than humans can review it; TrustGate checks every diff before it lands instead of trusting the agent's own account of what it did.
`TypeScript` `Git` `CLI`

**[codepilot-ai](https://github.com/abhishek-s12/codepilot-ai)** — Code intelligence platform with semantic search, call-graph navigation, and self-hosted chat over your own repo — fully local via Ollama, nothing leaves your machine.
`FastAPI` `React` `Qdrant` `Docker` `Ollama` · [live demo](https://codepilot-ai-wine.vercel.app/)

**chunkwiser** — Context engineering for large codebases: smarter chunking so LLMs stop hallucinating on repos they've never fully "seen." [Write-up →](https://dev.to/lintits/i-built-chunkwiser-a-tool-that-understands-large-codebases-without-hallucinating-ncp)
`Python` `RAG` `Vector Search`

**[packwiser](https://github.com/abhishek-s12/packwiser)** — Deterministic Rust packaging with signing, SBOMs, and supply-chain verification built in, for teams who need reproducible builds they can actually prove.
`Rust` `Ed25519` `SBOM` `CLI`
